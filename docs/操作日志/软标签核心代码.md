# 软标签（Soft Alias Encoding）核心代码归档> 用途：把真实类别标签映射到「别名块的软分布 / 别名单点」，让 B 方拟合补全头时无法对齐真实类。> 代码主体位于 `defense/purified\\\\\\\\\\\\\\\_vfl.py`，损失侧接线在 `core/trainer.py`，输出宽度注入在 `core/experiment.py`。> 本文档仅归档核心代码片段与调用链，机制与实验结论见《防御策略-PFNS软编码伪标签.md》。\---## 一、机制一览|项|硬编码（`labelAliasSoft=false`）|软编码（`labelAliasSoft=true`）||-|-|-||目标形式|块内随机 pick 单个别名（整数）|块内均匀概率分布（2D soft target）||类 c 的目标|`c\\\\\\\\\\\\\\\*K + randint(K) + base`|块内每列各 `(1-eps)/K`||损失|`CrossEntropyLoss`（整数标签）|`-(target·log\\\\\\\\\\\\\\\_softmax(logits)).sum(1).mean()`||逆映射|`(alias − base) // K`|同左（argmax 落在块内）|**别名布局**（二分类、K=2）：类 0 → 块 {4,5} 各 0.5；类 1 → 块 {6,7} 各 0.5。输出维度 = `2 × 真实类数 × K`，偏移 `base = 真实类数 × K`（别名不含 0/1）。\---## 二、参数表（`SUPPORTED\\\\\\\\\\\\\\\_PARAMETERS` 白名单 L205-212 + 赋值
