# PFS2 / PFS3 实验日志：软化的软标签（块外泄漏）

> 测试软标签的\\\*\\\*软化\\\*\\\*（label smoothing，块外泄漏 ε）在纯标签推断场景的效果。
> 核心机制：`labelAliasSmoothing` 参数 + `\\\_softLabel` 的块外泄漏逻辑。

## 一、核心机制

软化的软标签 = 块内为主 + 块外泄漏 ε：

```
类 c 的别名块 = \\\[c\\\*K+base, c\\\*K+base+K)
块内每个别名概率 = (1-ε) / K
块外每个位置概率 = ε / (outDim-K)
```

|ε|类 0 的 8 维向量|不同取值|
|-|-|-|
|0.0（PFS1，未软化）|`\\\[0, 0, 0, 0, 0.5, 0.5, 0, 0]`|{0, 0.5}|
|**0.1（PFS2）**|`\\\[.017×4, .45, .45, .017×2]`|{0.017, 0.45}|
|**0.2（PFS3）**|`\\\[.033×4, .40, .40, .033×2]`|{0.033, 0.40}|

### 核心代码（`defense/purified\\\_vfl.py`）

**块外泄漏逻辑** — `defense/purified\\\_vfl.py:2744-2752`

```python
eps = self.labelAliasSmoothing
inside = (1.0 - eps) / K
outside = eps / (outDim - K) if (outDim > K and eps > 0.0) else 0.0
if outside > 0.0:
    soft.fill\\\_(outside)
for k in range(K):
    col = (start + k).clamp(0, outDim - 1)
    soft\\\[index, col] = inside
return soft
```

## 三、结论

1. **软化（块外泄漏）不能把 LRA 压到随机**。ε=0.1 时只有 `d02\\\_amc` 从 0.6784 降到 0.6218（仍远高于随机 0.5），
`d03\\\_pmc` 的"低于随机"（0.48/0.45）是噪声波动（基线 0.5163 本身就在随机 0.5 附近）。
2. **两个已到/接近随机的场景被破坏**：`d02\\\_pmc`（0.50→0.73）与 `d05\\\_pmc`（0.65→0.76）大幅恶化。
3. **根本原因**：即使块外泄漏 ε，软标签仍是"块内高、块外低"的**两档结构**（块内 0.45 vs 块外 0.017），
"类 → 块"映射仍确定可辨，攻击者通过"哪些位置概率高"即可定位块。
4. **软化与可学性的根本矛盾**：ε 小 → 块内 >> 块外，块归属可辨（攻击者可读）；ε 大（→0.75）→ 块内 ≈ 块外，
标签信息消失（模型不可学）。**不存在能同时"隐藏块"和"保留可学性"的 ε。**
